# 母字双句公式库

只有在生成标题、比较句式或扩写变体时读取本文件。先匹配产品真实利益，再选公式；不要为了套公式扭曲产品事实。

## 选母字

母字应同时具备两层含义：一层能描述产品带来的变化，一层能落到用户的感受或动作。

| 产品利益 | 可选母字 | 常见落点 |
| --- | --- | --- |
| 降噪与专注 | 静、净、清 | 环境收静、内容听清、注意力回来 |
| 佩戴与便携 | 轻、小、巧、贴 | 减少负担、方便携带、贴合动作 |
| 音质与画面 | 清、真、沉、阔 | 细节、还原、沉浸、视野 |
| 续航与补能 | 久、满、续、快 | 用得更久、快速恢复、少被打断 |
| 连接与操控 | 稳、连、顺、快 | 少掉线、少等待、操作连贯 |

不要把品类名称误当母字。好的母字能够进入动词结构，例如“静下来”“听清楚”“轻装走”“稳稳连”。

## 六类句式

### 1. 母字回环

```text
[使用动作]挺X，X着[体验结果]
```

适合建立记忆点与口语感。两处 X 含义应略有变化，不能只是重复。

示例：听着更静，静着更好听。

### 2. 结构收放

```text
[产品端做减法]，[体验端做加法]
```

适合窄边框、小体积、降噪、轻量化等“产品收、体验放”的卖点。

示例：杂音收住，细节放大。

### 3. 外轻内大

```text
[外在尺度小]，[内在能力大]
```

适合小体积与大电池、大声场、高性能之间存在真实反差的产品。

示例：身形轻，续航长。

### 4. 母字延展

```text
为[对象或场景]而X，X出[最终价值]
```

适合新品类定位、场景专用设计或品牌主张。

示例：为通勤而静，静出一路好声音。

### 5. 事实结果

```text
[核心价值]所[动作]，[体验结果]尽[动作]
```

适合影像、音质、显示等强调还原与细节的卖点。

示例：真实所听，细节尽显。

### 6. 状态场景

```text
[能力状态]满满，[美好体验]+[时间或场景]
```

适合续航、能量、陪伴和全天候体验。

示例：电力满满，好音乐一整天。

## 从参数到标题

按“事实 → 用户变化 → 可感知动作 → 母字”转换。比如“耳机单耳重量较低”不是标题，先转成“长时间佩戴负担更小”，再提取动作“轻装、轻戴、轻松”，最后选择“轻”作为母字。参数仍放在证据行。

转换示例：

```text
事实：四麦克风协同处理环境声
用户变化：通勤时更容易听清内容
动作：环境声收住，内容细节出现
母字：静 / 清
标题：杂音收住，声音听清
```

## 替换式输入模板

```text
产品：{产品名}
品类：{品类}
核心卖点：{一个卖点}
目标用户：{人群}
使用场景：{场景}
已确认事实：{参数、结构、功能或测试条件}
希望强化的感受：{轻、静、清、稳、快、久等；可留空}
禁用表达：{品牌禁词、平台合规限制；可留空}
需要数量：{默认 6 组}
```

## 快速淘汰规则

出现以下任一情况就重写：换成多数竞品也完全成立；只有形容词没有动作；副标题只是把标题说长；一句中塞入两个以上独立卖点；为押韵产生歧义；证据无法支持标题承诺；明显接近某个品牌现成原句。
